## 3. 節奏規則（OMNI 提案）

- 真人總時長落在 **27–33%**；用逐句時間碼加總驗算，不要目測。
- 真人單段長度 1.5–4 秒；超過 4 秒就在中間插一個字卡或推近（同一顆鏡頭放大 108–115%）。
- B-roll 連續不超過 8 秒就要回到真人一次，避免觀眾忘記是誰在講。
- B-roll 段落內部用節拍格硬切（見 `殼層節奏與CTA_拆解.md` 第 2、6 節）；格長由實際配樂拍點決定。
- 「真人 ↔ B-roll」切換點可加 2–3 幀閃白或對到重拍；B-roll 之間不加轉場。
- 真人畫面上也要有動態：關鍵字大字卡、進度點、偶爾一次推近，不要是乾淨的純口播。
- 口播聲音全程不中斷：B-roll 是蓋在聲音上面的畫面軌，不是把口播剪掉。

## 4. 特效挑選規則

- 用 `FX30_逐幀拆解資料庫.md` 末尾的「用途速查表」依句型選。
- 一支 60–90 秒的片用 **8–12 個不同特效**，同一特效不重複（章節卡與 CTA 例外）。
- 開工前讀 `使用輪替紀錄.md`：**最近兩支片用過的特效這次不用**，優先挑還沒用過的。完工後把這支片用了哪些寫回去。
- 相鄰 B-roll 明暗交替。
- 涉及收入、名額、人數的畫面右側加「示意」小字；金額一律標「潛力上限，非預期收入」，不出現保證式用語。
