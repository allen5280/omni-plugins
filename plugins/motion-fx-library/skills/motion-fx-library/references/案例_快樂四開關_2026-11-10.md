## 流程（照這個順序做）

1. **字級轉錄**：faster-whisper large-v3，`word_timestamps=True`。模型用 curl 直接抓 `Systran/faster-whisper-large-v3` 五個檔，不要走預設下載器（會卡住）。
2. **找重講**：環境有底噪時 `silencedetect` 完全抓不到停頓。改用 250–3500 Hz 頻帶能量、門檻 = 底噪 + 33% 動態範圍，找出 ≥ 0.22 秒的停頓；再把每個「語音島」單獨轉錄，才看得到被 Whisper 合併掉的重講。這支片抓到 6 處重講，一律取最後一個完整的 take。
3. **跳剪**：每段保留到停頓裡（用原音的環境音當間隔，不插數位靜音），句間 0.10–0.14 秒、換章 0.30 秒、情緒句前後 0.40 秒，切點 6–8 毫秒淡入淡出，最後 `loudnorm I=-15`。
4. **鏡頭表**：每句標真人或特效，鏡頭切點 = 該句起點前 0.06 秒並對齊到幀；場景內的動畫節點（換數字、蓋章、亮燈）用該句的時間當 cue 傳進引擎。
5. **特效**：`render(t)` 逐幀引擎，Playwright 截圖 → ffmpeg，原生 2160×3840。三路平行，21 段約 12 分鐘。逐段核對幀數。
6. **真人段**：`-ss` 精準定位後 `fps=24`，推近用 crop＋lanczos（1.08／1.14 倍，錨點在畫面高度 30%），情緒句用逐幀 scale 做慢推。
7. **合成**：concat → 燒 ASS 字幕 → x264 crf 16。
8. **交付**：HEVC 4K（hvc1、7.3 Mbps）給手機；剪映草稿用真實素材探測後產生，素材路徑用佔位字串，由安裝腳本換成實際解壓位置。

## 踩到的坑

- 插畫主體要落在畫面 18%–63% 高度，字幕帶（64%–73%）才不會被壓到。
- 特效上的字不要跟字幕講同一句：章節卡放的是口播沒講的副標。
- 沙盒指令裡 `pkill -f 關鍵字` 會殺到自己，要寫成 `pkill -f "[關]鍵字"`。
- 背景編碼被中斷後重跑，一定換輸出檔名；兩個程序寫同一個檔會產生「看起來正常、實際解不開」的檔案。交付前跑一次完整解碼（`ffmpeg -v error -i 檔 -f null -`）。
- 上傳單檔上限約 100 MB：成品改 HEVC、素材包拆成多個 zip。
- 剪映草稿套件用 `pyJianYingDraft==0.2.7`；0.3 版的 API 不同。

## 沒做到、或沒驗證的

- 沒看到 E 槽的核心卡與蒙格成片，標準是 Notion《故事行銷爆款公式》第 19–23 章＋FX30。
- 聲音沒有人耳驗收：跳剪點、響度、底噪只做過量測。
- 剪映草稿沒有在真的剪映裡開過；進度膠囊只燒在成品裡，草稿沒有。
- 「小貓小狗對看」那句引用的 Science 2015 研究對象是狗與飼主，畫面只畫了狗。
- 片尾口播有一句「轉發給你在乎的人」，Notion 正典第 19-5 節提醒這類語句可能被判定為誘導互動；口播原句沒有改動。

## v2｜蒙格基底版（同日）

柏維哥傳來蒙格成片後的指示：以蒙格為基底，字幕與音效全部照蒙格，真人約 30%，可摻入 v1 的場景。

- 做法：不重做內容，只換「皮」。在 v1 引擎外面加一層覆寫（`fx3.html`）：共用的蒙格背景函式、HUD 角框、金色襯線章節卡與金句卡；把 v1 各場景的底色與字色整批換成深藍黑＋金；版畫插畫用色彩鍵去掉紙色、深藍墨改成淺金，變成暗底上的金線稿。
