## 2. 製作流程（每一步對應的腳本）

| 步驟 | 做什麼 | 腳本 |
|---|---|---|
| 1 | Whisper large-v3 逐字轉錄；用頻帶能量找停頓（商場環境音讓 silencedetect 失效）；重複的句子留最後一次完整的 | `cut.py` → `plan.json` |
| 2 | 每句標真人或 B-roll、分配場景、定鏡頭邊界（全部落在 24fps 整數幀） | `plan.json` 的 `shots` |
| 3 | 生 8 張版畫插畫（Higgsfield gpt_image_2_6，一次批次）；轉成透明金色版 | `recolor_plates.py` |
| 4 | 用瀏覽器畫布逐幀渲染 21 個 B-roll 片段（2160×3840、crf 10） | `fx3.html` + `render5.js` |
| 5 | 真人段依跳剪表裁切、放大、壓暗角（crf 10） | `build3.py pieces` |
| 6 | 字幕渲成兩條透明 PNG 序列：底部字幕帶、上方金色標題帶 | `render6.js` |
| 7 | 片段接起來＋疊兩條字幕帶，前後兩半各自編碼再無損接合；混音 | `final3.py A / B / mux` |
| 8 | 剪映草稿（分層版）與安裝程式 | `mkdraft3.py`、`pack4c.py` |
| 9 | 交付：四段上傳＋下載頁在瀏覽器裡自動接成一個 mp4 | `download_page.html` |
