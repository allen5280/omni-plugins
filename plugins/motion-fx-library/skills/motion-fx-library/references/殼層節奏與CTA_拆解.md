# 殼層、節奏與 CTA 拆解（參考片的「骨架」）

> 30 個特效是肉，這份是骨架。骨架才是這支片留得住人的原因。

## 1. 時間結構（實測）

| 區段 | 幀 | 秒 | 內容 |
|---|---|---|---|
| 特效展示 | 1–990 | 0.0–33.0 | 30 個特效 × 33 幀，全部硬切 |
| 模糊轉場 | 991–1012 | 33.0–33.7 | 預覽窗變黑 → 整個視窗高斯模糊淡出 → 標題模糊變形成 CTA |
| CTA | 1013–1104 | 33.7–36.9 | 留言卡模擬 |

- **節拍格 ＝ 33 幀（1.1 秒）**。場景偵測在 3.3、4.4、5.5 … 30.8、33.0 秒全部命中，零例外。
- 1.1 秒一刀對應約 109 BPM 的兩拍（這是由剪點間隔推算的，**音樂本身沒有聽過**，下一支片要用實際配樂的拍點重算格長）。
- 音軌全程等響度、沒有靜音段（每秒 RMS 幾乎持平）。雲端容器沒有語音辨識工具，旁白內容未轉錄。

## 2. 每個 1.1 秒鏡頭內部的固定節奏

```
幀  0        3            9–12              18–21           27–30      32
    │閃白/砸入│ 主體到位     │ 次要元素出現      │ ★換字/換數字    │ 收尾對焦   │硬切
    └ 鉤子 1 ─┴─────────────┴──────────────────┴─ 鉤子 2 ───────┴───────────┘
```

1. **前 3 幀就要有東西**：亮底特效第 0 幀過曝閃白（3 幀內收斂），暗底特效用光刃／光暈／砸入。
2. **主體 0.3–0.4 秒內到位**，之後只做次要動態（旋轉、滾數、亂碼）。
3. **第 18–21 幀安排一次「換」**：換數字、換詞、換頁、換步驟。一個鏡頭兩個鉤子。
4. 最後 5 幀通常是一行小字由模糊對焦，然後硬切。
5. **除了片尾，全片沒有任何溶接、滑動、縮放轉場。** 轉場感來自每個特效自己的進場。

## 3. 殼層（包住所有特效的固定外框）

畫面 720×1280，以下座標為原片像素（換到 1080×1920 全部 ×1.5）。

| 元件 | 位置 | 規格 |
|---|---|---|
| 背景 | 全畫面 | 近黑 `#0C0C0B`，頂部一團綠色徑向光暈（中心 `#496820` → 透明），帶極淡的垂直細線紋 |
| 主標第一行 | y≈200 置中 | 白色極粗黑體「30 種 CLAUDE」，高約 56px |
| 主標第二行 | y≈285 置中 | 螢光黃綠 `#CFFF5F` 極粗黑體「動畫特效」，高約 80px，同色外發光 |
| 終端機視窗 | x30–690, y375–1010 | 圓角 18px，底 `#131416`，標題列 `#191D1E` |
| 紅黃綠三點 | 左上 | `#EA4C5A` `#F5BB3D` `#3AE14C` |

| 檔名列 | 左 | 「▶ /ex-speed-echo-number.mp4」**每個鏡頭換檔名** |

| 進度條 | y≈982 | 底軌 `#242527`，進度 `#E0FF7F`，每個鏡頭前進 1/30 |

**留人機制**：計數器＋清單反白＋進度條 ＝ 三重「還有多少沒看」的進度提示。觀眾看到 05/30 會想看到 30/30。清單會隨進度向上捲動，讓反白條停在中上位置，並且永遠露出後面 6–8 個名字（預告）。

**套用到柏維哥的片**：真人口播片不適合全程套殼，但「清單型段落」（例如「這套系統做了 7 件事」）可以用 5–10 秒的殼層段落 —— 左邊預覽窗放特效，右邊清單逐項反白。

## 4. 片尾 CTA（3.9 秒，已實作 `cta_comment`）

| 相對秒（幀） | 動作 |
|---|---|
| 0.00–0.25（f991–998） | 預覽窗先變黑；整個視窗高斯模糊（半徑 0→約 30px）並淡出 |
| 0.20–0.50（f997–1006） | 主標原位模糊變形：白字「留言」先對焦，第二行螢光綠「「動畫」」帶外發光隨後對焦 |
| 0.45–0.65（f1004–1010） | 深色留言卡淡入（左上小字「你」）；下方輸入列淡入（「新增留言…」＋螢光綠圓形送出鍵） |
| 0.85–1.03（f1016–1022） | 留言卡內逐字打出關鍵字（每字約 3 幀） |
| 1.25–1.57（f1028–1038） | 關鍵字後方紅色愛心彈跳（先放大過衝、再回到正常大小） |
| 1.77–2.00（f1044–1050） | 作者回覆卡由下滑入：「作者・回覆」／一句承諾／螢光綠「打開連結 ↗」 |
| 2.00–3.90 | 靜止約 1.9 秒，讓人讀完並行動 |

**原理**：不是叫觀眾留言，而是**演給他看留言之後會發生什麼**（打字 → 愛心 → 作者回覆連結）。把行動的回報視覺化。

## 5. 色彩與字體

- 殼層只有三個顏色：近黑、白、螢光黃綠 `#CAFF47`。**所有彩色都留給預覽窗裡的特效。**
- 相鄰鏡頭的底色明暗交替：30 個鏡頭裡沒有連續 4 個同明度的底。暗（01–03）→ 亮（04）→ 暗（05）→ 亮（06）→ 暗（07）→ 彩（08）…
- 每個特效自成一套美術（金屬／瓷／黏土／紙／版畫／霓虹／線框／等距／瑞士平面／日式繪卷），但共用三條規則：單一主體置中、一個超大字或數字、每屏中文不超過 12 字。
- 字體角色：極粗黑體（標題與數字）、高反差襯線斜體（巨型數字）、明體／宋體（文青感標題）、等寬字（HUD、計數器、代碼）。
- 特效內字幕：白色粗體單行、無底框、位置在畫面高度 68–72%、字高約為畫面高度的 2%。
- 多個特效右側有極小的「示意」二字 —— 示意畫面的免責標註。**柏維哥涉及收入、名額、人數的畫面一律比照加上。**

## 6. 下一支片可直接照抄的七條

1. 配樂定了之後，用拍點算出節拍格（幀數），所有 B-roll 長度取格長的整數倍。
2. B-roll 之間全部硬切；只有「口播 ↔ B-roll」切換點可以加 2–3 幀閃白。
3. 每個 B-roll 鏡頭在中段安排一次換字／換數字。
4. 相鄰 B-roll 明暗交替。
5. 清單型內容用殼層段落（計數器＋清單反白＋進度條）。
6. 片尾用留言卡模擬，關鍵字換成當支片的關鍵字。
7. 示意性的數字畫面右側加「示意」小字。
