## 2. 字幕（實測，2026-11-10 v3 重新量過，以這一版為準）

蒙格片的字有**兩層**，不要混在一起做：

| 項目 | 720p 實測 | 1080×1920 做法 |

抽查 38 句底部字幕，**沒有任何一句出現金色**。

### 2b. 金色重點標題（在畫面上方，不在字幕位置）

重點句與章節句不走底部字幕，而是在**畫面上方**逐字打出金色明體標題；那一句的底部字幕讓位（空白）。標題可以停留到後面幾句，這時底部銀白字幕照常出現。

| 項目 | 720p 實測 | 1080×1920 做法 |
|---|---|---|
| 位置 | 佔畫面高度 12%–26% | 兩行：第一行中心 y=266、第二行中心 y=392；單行：中心 y=284 |
| 字體 | 粗明體 | Noto Serif TC **900** |
| 字級 | 一般字高 51、重點字高 58 | **柏維哥 2026-11-10 指定：同一句全部等大，不要放大重點詞** → 全部 84px（蒙格原片是重點字 102px，我們不照這一點） |
| 顏色 | 上 (243,221,169) → 下 (225,191,130)，高光到 (255,233,174) | 每字直向漸層 `#F7E4B4` → `#F1D9A3`(35%) → `#E8CB91`(70%) → `#DCB877`；柔黑陰影＋淡金外光 |
| 進場 | 逐字打出（約 12 字 2 秒） | 每字間隔 min(0.075 秒, 句長×0.5÷字數)，帶 0.12 秒的模糊淡入 |
| 英文 | 標題下方一行明體，暖白 (237,232,229) | Playfair Display 400、42px、`#EDE8E5`；兩行標題時基線 y=478，單行時 y=378；標題打完後淡入 |
| 襯底 | 蒙格片整體壓暗，標題下方夠黑 | 疊在真人畫面上時，加一層由上往下淡出的暗色漸層（頂端 66% → y=720 歸零），只在標題出現時存在 |

排版規則：同一句話字體大小一律相同（金色標題與銀白字幕都一樣），不做大小字混排，畫面才不亂；一句 4–9 個字；一支 90 秒的片用 8 句左右，再多就不是重點了。

## 4. 聲音結構（量測）

- **持續的氛圍襯底**：人聲安靜的片段，頻譜能量仍有全片平均的 85%；主要頻率在 322–333、430–441、645–656 Hz 與 32–43 Hz。
- **高頻音效 46 個**（約每 2.3 秒一個），落在換鏡頭與畫面節點上。
- **低頻重擊 7 個**：0.9、41.0、50.3、61.6、62.6、62.8、91.0 秒，對應章節與重點畫面。
- 重現方式：A 小調的氛圍襯底（110／165／220／262／330／440／659 Hz 正弦疊加、慢速起伏）；切入特效時的呼嘯聲；場景節點的鈴音；章節與大數字的低頻重擊。**這是「同結構的合成版」，不是原始音效檔**；桌機上的蒙格產線有原始音效，能用就換回去。

## 5. 鏡頭節奏
