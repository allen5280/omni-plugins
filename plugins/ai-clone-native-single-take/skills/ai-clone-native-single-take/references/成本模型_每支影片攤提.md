## 2️⃣ 單支 52.5 秒影片的變動成本

### ① a-roll 數字人（HeyGen）
```
52.5 秒 ÷ 60 = 0.875 分鐘 × US$3.00 = US$2.63
重跑係數 1.1（Avatar IV 近乎決定性＋正典 prompt＋已驗證底圖，很少要重跑）
→ US$2.89
```

### ② 克隆配音（MiniMax）
```
文案 344 漢字 ≈ 688 計費字元（中文 1 字 ≈ 2 字元，實測 24 漢字 → usage 48）
管線跑 4 次（1 次語速校準 + best-of-3）= 2,752 字元
2,752 ÷ 1,000,000 × US$100 = US$0.28
```
> 💡 **可優化**：校準改用前 60 字取樣（不用跑全文）→ 降到 **US$0.19**，省 32%

### ③ B-roll（Higgsfield，月訂閱攤提）
```
混合模式（Pexels 實拍為主）：每支約 2 段 AI 客製 × 4.5cr =  9 credits
全 AI 模式：              每支約 5 段 × 4.5cr × 1.3 重生 = 29 credits
```

### ④ 底圖（一次性）
```
perfect_v3 = 4 credits ≈ US$0.20，攤提到 100 支 → US$0.002（可忽略）
```

### ⑤ 字幕／音效／Pexels → **US$0**
